# Café & Art Space

Небольшая 3D-игра для Маши в эстетике тёмного фэнтези: готическое кафе на колёсах, ночной лес, башенки, золотые рамы, книги и тёплый свет.

## Запуск

Откройте `dist/index.html` в современном браузере с WebGL. Нужен интернет: Three.js 0.160.1 загружается с jsDelivr. Остальные модели и изображения создаются кодом, внешних ассетов нет. Исходная плоская открытка сохранена отдельно в `postcard.html`.

При желании запустите `python -m http.server 8080 --directory dist` из папки `masha`, затем откройте http://localhost:8080. Для размещения на статическом хостинге загрузите папку `dist` целиком.

## Игра

Потяните мышью или пальцем, чтобы повернуть дом. Колесо мыши меняет расстояние. Нажмите «Постучаться в дверь», затем выполняйте задания:

1. Найдите картину с морем.
2. Откройте бордовую книгу.
3. Выпейте кофе.
4. Зажгите звезду мечты и прочитайте поздравление.

Предметы выбираются непосредственно в 3D или кнопками в панели. «Где искать?» показывает подсказку и кольцо вокруг нужного предмета. Неверный выбор не пропускает сюжет. Кнопка ↺ начинает заново. Escape продолжает историю так же, как кнопка «Дальше».

## Файлы

- `dist/game.js`: объёмная сцена, камера, освещение, анимации, выбор предметов.
- `dist/game-state.js`: задания, тексты и порядок прохождения.
- `dist/style.css`: интерфейс для компьютера и телефона.
- `game-state.test.cjs`: проверки прохождения и перезапуска.

Проверка: `node --test game-state.test.cjs`.

Синтаксис JavaScript и тесты сценария проверены. Проверка отображения и взаимодействий в настоящем браузере не выполнена: среда блокирует запуск Chrome. Сайт не опубликован.
